Privacy Policy

Last updated: 24 November 2026

What this covers

This policy covers the Google OAuth application drive-sync and other personal tools published by Zoran Jezdimirović that access Google Drive. They are private tools used only by their owner to reach his own Google Drive from his own computers.

Data accessed

  • Files and folders in the signed-in user's Google Drive, and their metadata, so the Drive can be mounted and used as a local folder.
  • No other Google data (contacts, mail, calendar) is requested.

How data is used and stored

  • Data moves only between Google Drive and the user's own computer.
  • Files may be cached on that computer's disk to make access faster. The cache never leaves the computer.
  • The OAuth token is stored only in a local configuration file on that computer.

Sharing

No data is sold, shared with or transferred to third parties, and none is used for advertising or analytics. There is no server that receives user data.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local configuration file removes the stored token.
